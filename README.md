# 본사2지부 문화행사 퀴즈 & 경품 추첨

- 참여자 화면 (QR 연결 주소): https://wony7896.github.io/hq2-quiz/
- 진행 화면 (스크린에 띄우는 화면): https://wony7896.github.io/hq2-quiz/host.html
- 사전 질문 (조합원에게 메일로 보내는 주소): https://wony7896.github.io/hq2-quiz/ask.html

## 조합원 사전 질문

1. 위 사전 질문 주소를 메일로 보냅니다. 조합원은 로그인 없이 이름을 적지 않고 질문을 남깁니다.
2. 진행 화면의 **설정 → 조합원 질문**에 질문이 쌓입니다. 새 질문을 **화면에 올리기** 또는 **보류**로 나눕니다.
3. **올릴 질문** 목록에서 ▲▼로 순서를 정하고, 필요하면 화면에 띄울 문구로 다듬습니다. 원문은 그대로 남습니다. 이름은 화면에 나오지 않습니다.
4. 올릴 질문은 그 순서대로 표지 다음 화면에 한 장씩 나옵니다. **올릴 질문 N개 복사**로 위원장에게 미리 전달할 수도 있습니다.
5. 접수를 끝낼 때 **접수 마감하기**를 누릅니다. 전체 초기화를 해도 질문은 지워지지 않습니다.

## 행사 전 준비

1. 진행 화면을 열고 관리자 PIN으로 로그인합니다. (PIN은 이 저장소에 없습니다)
2. 아래 도구 막대의 **설정 → 문제**에서 10문제를 입력하고 **문제 저장**을 누릅니다.
   - 왼쪽 동그라미로 정답을 고릅니다. 보기는 2~4개, `O/X 문제로` 버튼으로 O/X 문제를 만들 수 있습니다.
   - 해설을 적으면 정답 공개 때 화면에 함께 나옵니다.
3. **설정 → 행사 정보**에서 제목과 부제를 바꿀 수 있습니다.
4. 리허설: **설정 → 참여자·초기화 → 테스트 참여자 30명 추가**로 혼자서 끝까지 넘겨 봅니다.
5. 행사 직전 **전체 초기화**를 눌러 리허설 기록을 지웁니다. (문제는 남습니다)

## 진행 순서

| 화면 | 다음으로 넘기면 |
|---|---|
| 표지 (행사 이름, 큰 QR, 실시간 참여자 수) | 조합원 질문 (올릴 질문이 없으면 1번 문제) |
| 조합원 질문 (한 장에 한 질문, 위원장 답변 시간. 참여자 휴대폰에는 대기 안내만 표시) | 다음 질문 … 끝나면 1번 문제 |
| 문제 (참여자 휴대폰에 보기 표시, 응답한 사람 아이디가 실시간으로 쌓임, 제한시간 30초) | 정답 공개 (정답·보기별 응답률, 맞힌 사람 아이디는 파란색) |
| 정답 공개 | 정답자 추첨 화면 |
| 정답자 추첨 | 추첨 → 룰렛 (약 7초, 마지막 3초는 점점 느리게) → 당첨자 공개 → 닫기 → 다음 문제 … 10번까지 |
| 퀴즈 결과 (참여자·평균·만점자 수, 정답 개수별 인원 그래프. 막대 대신 참여자 이름을 쌓고 팀명은 뺌. 만점자 칸은 금색. 아래 줄에 만점자, 만점자가 없으면 최다 정답자 이름) | 만점자 추첨 (만점자가 없으면 최다 정답자 추첨) |
| 만점자 추첨 / 최다 정답자 추첨 (후보 아이디가 크게 보임, 문제별 당첨자는 제외) | 추첨 → 룰렛 (약 7초, 마지막 3초는 점점 느리게) → 당첨자 공개 → 닫기 → 마무리 |
| 마무리 | — |

- 제한시간은 문제를 처음 열 때 시작되고, 끝나면 답을 받지 않습니다. 정답 공개는 시간이 남아 있어도 넘기면 바로 진행되고, 그 뒤로는 이전 화면으로 돌아가도 다시 답할 수 없습니다.
- 시간을 다시 재야 하면 아래 도구 막대의 **30초 다시**를 누릅니다. 리허설로 흐른 시간은 **전체 초기화**로 지워집니다.
- 정답자 추첨은 그 문제를 맞힌 사람 중 아직 당첨되지 않은 사람에서 한 명을 뽑습니다. 한 사람은 한 번만 당첨됩니다.
- 정답자 추첨 화면에는 그 문제를 맞힌 사람 아이디가 크게 보이고, 넘기면 그 아이디들이 적힌 룰렛이 돌아 한 명이 뽑힙니다.
- 룰렛 판에는 최대 20명(당첨자 포함 무작위)이 들어가고, 바늘이 가리키는 아이디는 오른쪽 이름판에 크게 나옵니다.
- 한 문제에서 더 뽑고 싶으면 **한 명 더 추첨**, 당첨자가 자리에 없으면 **당첨 취소**를 누르고 다시 넘깁니다. 맞힌 사람이 없으면 바로 다음 문제로 넘어갑니다.

- 다음: `→` `Space` `Enter` `PageDown` (프레젠테이션 리모컨 사용 가능)
- 이전: `←` `PageUp`
- 추첨 화면에서 마무리로 가기: `↓` 키 또는 아래 도구 막대의 ▶
- 전체화면: `F`
- 마지막 추첨 대상은 자동으로 정해집니다. 문제별 정답자 추첨 당첨자를 뺀 사람 중 가장 많이 맞힌 정답 수가 기준입니다.
  - 만점자가 있으면 **만점자 추첨**: 모든 문제를 맞힌 사람 중에서 뽑습니다.
  - 만점자가 없으면 (또는 만점자가 모두 문제별 추첨에 당첨됐으면) **최다 정답자 추첨**: 그다음으로 가장 많이 맞힌 사람들 중에서 뽑습니다. 예) 최고 8개 → 8개 맞힌 사람들 중 추첨.
- 화면 오른쪽 위 **정답 N개 이상**의 −/+ 로 기준을 바꿀 수 있습니다. 대상자를 모두 뽑은 뒤 그다음 정답 수까지 넓혀 더 뽑을 때 씁니다. 바꾼 기준은 참여자 휴대폰의 '추첨 후보' 안내에도 반영되고, 전체 초기화·당첨자 초기화를 하면 자동 기준으로 돌아갑니다.
- 마지막 추첨도 **한 명 더 추첨**과 **당첨 취소**를 쓸 수 있습니다.
- 휴대폰: 추첨 후보에게는 "만점이에요!" 또는 "가장 많이 맞혔어요! 나도 추첨 후보예요"가, 당첨자에게는 "만점자 추첨 당첨" 또는 "최다 정답자 추첨 당첨"이 보입니다.
- 결과 그래프와 아래 이름 줄은 아이디에서 팀명을 뺀 이름만 보여 줍니다. "홍길동 BX팀", "홍길동/BX팀", "홍길동BX팀"처럼 붙여 쓴 경우도 이름만 남깁니다. 추첨 화면과 당첨 화면은 누군지 알아볼 수 있도록 아이디 전체를 보여 줍니다.
- 당첨자 휴대폰에는 연출이 끝난 뒤 "당첨을 축하합니다" 화면이 뜨고, 다음 문제가 나오면 다시 문제를 풀 수 있습니다.

## 구조

- `index.html` 참여자 화면, `host.html` 진행 화면, `ask.html` 사전 질문 화면, `assets/` 공통 코드
- 데이터는 Supabase(flyer 프로젝트)의 `quiz_` 표에 저장되며, 브라우저는 `supabase/schema.sql`과 `supabase/migrations/`의 함수만 호출합니다.
- 정답은 정답 공개 전까지 참여자에게 전달되지 않고, 진행자 기능은 모두 PIN을 확인합니다.
- 색상은 `assets/base.css`의 `--b-blue` 값 하나로 바꿀 수 있습니다.
